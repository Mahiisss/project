# Basic Frontend Project

A simple, responsive frontend project built with **plain HTML, CSS and JavaScript** — no frameworks, no build tools.

## Features

- Responsive layout with a mobile hamburger menu
- Light / dark mode toggle (saved in `localStorage`)
- Task list — add, complete, delete, filter and clear tasks (saved in `localStorage`)
- Contact form with client-side validation

## Project Structure

```
basic-frontend-project/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── .gitignore
└── README.md
```

## Run Locally

Just open `index.html` in your browser.

Or use the **Live Server** extension in VS Code for auto-reload.

## Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/Mahiisss/basic-frontend-project.git
git push -u origin main
```

## Deploy with GitHub Pages

Repo → **Settings** → **Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → **Save**.

Your site will be live at `https://mahiisss.github.io/basic-frontend-project/`.

## Tech Stack
